# keepmeta

Keep URLs and meta query parts with stable normalization.

**Site:** https://theworker02.github.io/keepmeta/

## Install / run

```bash
git clone https://github.com/theworker02/keepmeta.git
cd keepmeta
node src/cli.js
node --test
```
